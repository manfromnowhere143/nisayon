test and the [current native comparison](experiments/results/native-sdk-2026-10-23/README.md).
The XPolicyLab development replay is exposed and cannot serve as the untouched

## Intake and selection

Use one current owner-approved change outside the separate LeRobot lane. Retain
the owner's decision question, working reference, changed implementation,
existing failure records, allowed execution environment and applicable task
criterion. Resolve ambiguous semantics with the owner before treating a
difference as a defect. Cap initial intake at four hours and retain an unresolved
outcome if the case cannot become testable within that ceiling.

Before execution, freeze both arms' native tools, information, model access,
allowed interventions and complete budgets. The competent baseline is the
owner's native tools plus a capable agent. An intentionally weak script is not
that baseline. Record all material already exposed to the builder and identify
who owns any fresh or reserved answers. A source worktree or file permission is
not an evaluation-isolation boundary.

## Decide before observing

Freeze the outcome-quality criterion, intervention-selection rule, failure
controls, subgroup requirements, task acceptance rule and stopping conditions.
Preserve the existing 32-pair fresh confirmation obligation wherever it applies;
the portable JSON-call adapter does not discharge it. Action-changing experiments
must recompute downstream state and observations using a qualified native task
adapter. A candidate that only stops the robot does not repair its task.

Report software qualification and deployment acceptance separately. Account for
invalid, failed, unresolved, inconclusive, supported and contradicted results.
Unexecuted confirmation remains unexecuted. Never reinterpret an original
numerical failure as a pass after relaxing its tolerance; a changed precision
policy is a new declared candidate.

## Measure the entire comparison

Retain intake, setup, adapter edits, diagnostic trials, retries, model usage,
confirmation, review, adoption and maintenance. Report human effort, provider
charges, compute and wall time in their original units. Reconcile nested clocks
without adding them twice. Missing costs stay unknown. The historical target
is at least a twofold reduction in complete cost at matched decision quality;
meeting a partial runtime target is insufficient.

The new adapter's process startup and environment inspection are measured work.
A more elaborate record can be slower than native tooling. Equal or worse
complete cost at matched quality is a valid negative product result, not a
reason to hide the comparator or reclassify setup as free.

## Test reuse separately

After the first case, freeze the reusable procedure and applicability map.
An evaluator who has not exposed the second case's answers selects a separate
incident within the declared scope. Preserve every adaptation, failed attempt
and request for help as part of the reuse cost. Compare against equally informed
native tools and agent access. A changed population, scorer, state contract or
dependency requires new evidence; a retrieved verdict cannot grant acceptance.

If the second case requires another bespoke subsystem, revise the product
scope. Only after this gate should selection research compare expert rules,
the finite planner, procedure retrieval and a learned selector. Use equal
information and budgets, including no-memory, stale-memory and restart controls.
Hosted execution needs a demonstrated remote execution or shared review need.
