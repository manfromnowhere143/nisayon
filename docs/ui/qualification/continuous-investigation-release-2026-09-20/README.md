## Automatic publication boundary

The installed 60-second LaunchAgent remains a consumer of sealed evidence.
This release's committed archive bridges the older producer declaration.
Changed committed declarations in the engine's normal retained-output contract,
or its temporal revalidation contract, supersede that bridge. Each update must
pass current dependency and raw-artifact verification before any promotion.
The bridge does not silently relabel an obsolete export as current.

The job verifies immutable runtime bytes, stages the projection, reads back
evidence plus workers and geometry through authenticated Vercel access, checks
the source again, then promotes. The public domain is checked anonymously.
Old Study objects remain addressable. Staging authentication remains enabled.
The operator Mac, network, source stores and existing credentials are required;
there is no always-on hosted publisher or live execution heartbeat.
