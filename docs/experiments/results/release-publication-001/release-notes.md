Nisayon executes bounded experiments on learned robot-policy integration failures and checks whether a correction has valid evidence, fresh confirmation and preserved task progress. This release contains the CPU Lift adapter, evaluator, validity controls, locked dependencies and compact reproduction records.

Separately hosted policy weights, training data, private development history and full simulator stores are outside this distribution; see the [asset terms](https://github.com/manfromnowhere143/nisayon/blob/v0.1.0/docs/experiments/ASSETS.md).

A is the competent conventional workflow; B has equivalent information and opportunities plus additional checks. B's scripted checks changed no decision, and the bounded live-model arm requested no optional audit. Both arms used the common execution and mandatory confirmation service. Three repetitions of one known incident are not three independent incidents. Human effort, provider charges and energy remain unknown. These results establish no efficiency advantage, physical-safety guarantee or unseen-fault benchmark result.
