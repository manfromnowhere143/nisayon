## Premises and mathematical obligation

The caller declares a finite hypothesis set, deterministic predictions for each
observed input and candidate offline probe, a common absolute error bound and
positive integer probe costs. Those costs count software observations only.
At least one declared hypothesis must describe the measured mechanism within
that error bound for identification to mean anything beyond model fit.

Retain every hypothesis whose largest absolute residual is within the bound.
Zero survivors is model mismatch; several survivors is unresolved. A single
survivor identifies only within the declared set. Never use a tie-breaker as a
root-cause conclusion. NaNs, infinities, duplicate identities, missing prediction
coverage, incompatible shapes and invalid costs are invalid input.

Two hypotheses can be distinguished by a probe only when their prediction
vectors differ by more than twice the error bound in at least one coordinate.
This follows from disjoint closed infinity-norm balls. A set of probes identifies
every surviving hypothesis when it separates every pair. Solve minimum total
integer cost exactly over the supplied finite pool, within a small explicit
enumeration limit. If some pair cannot be separated, report it and return
unresolved within this pool. Do not imply that identification is impossible
with other observations, or that a partial cover is a complete plan.
