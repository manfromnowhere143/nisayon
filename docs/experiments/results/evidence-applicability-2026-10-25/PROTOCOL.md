# Explicit applicability qualification

25 October 2026. Prospective local protocol, before comparison execution. This
qualifies the new dependency planner on an exposed native integration. It does
not enroll an external owner or satisfy independently selected untouched reuse.

The decision is whether the declared normalization wrapper still meets its
numerical contract after a calibration or scoring change. Use the existing
byte-identical OpenPI loader at `215abfb217dbac7d5f1273282331b9b1866c0479`,
the retained minimal locked interpreter, and the existing controlled wrapper.
No policy weights, training, robot, simulator, paid compute or external message.

Freeze the dependency definition, review, planner, native selector, worker and
comparison driver before execution. A review here is a retained code/model
review performed in this development context, not independent human acceptance.
Bind code, calibration, diagnostic inputs, runtime, reset convention, scoring,
population, confirmation inputs and procedure identities explicitly. Every
decision requires fresh native confirmation and review. Changed scoring can
reuse raw observations; changed calibration must execute new observations.

Both workflows receive the same native code, inputs, scoring rule, dependency
knowledge, negative control, raw outputs and fresh confirmation. Native Python
uses a small fixed selector written for this reviewed dependency model. It may
reuse the same unaffected evidence. Full rerun is a diagnostic reference, not
the claimed competent baseline. Randomize serial arm order once, record it
before execution, preserve every failed prefix and never drop a case.

Declared exposed sequence, with the same diagnostic inputs throughout:

1. Mean `[10.05, 10, 10]`, standard deviations 10, tolerance 0.01: adopt.
2. Same calibration, tolerance 1e-12: reject; reuse observations and rescore.
3. Correct means to `[10, 10, 10]`: adopt; execute new observations.
4. Wrong first mean 15: reject; execute new observations.
5. Same wrong calibration and unknown target population: unresolved.
6. Restore correct calibration and declared population: adopt.

Generate and retain 32 new confirmation vectors per decision before the first
arm runs. Inputs are exposed to the implementer; fresh means different from
the diagnostics and preceding confirmations, not a reserved independent test.
Require reference agreement and a discriminating negative control as well as
candidate agreement. An unknown population prevents acceptance. Retain all raw
role outputs, file identities, commands, exit codes and phase clocks.

Then run the exact frozen procedure again in a new directory with newly
generated confirmation inputs. This tests unchanged procedure operation only.
It does not turn this exposed sequence into independently selected reuse.

Report every paired decision and false acceptance among the unsuitable cases.
An unexpected decision invalidates matched quality regardless of execution
cost. Retain all eight complete-cost phases: intake, setup, diagnosis, retries,
confirmation, review, adoption and maintenance. Measured process time is a
component, not active owner effort or total engineering cost. Common preparation
belongs to both comparisons; development, research, failures and review are not
free. Unknown human/provider/longer-term costs remain null. The retained target
is at least a twofold complete-cost reduction at matched decision quality;
missing costs leave that target unresolved.

Do not tune the selector to the observed labels. A changed procedure requires a
new freeze and retention of the original attempt. Graph coverage is conditional
on declaration completeness. A deliberately omitted dependency may be
undetectable when another input of the same kind remains; the planner must not
claim automatic completeness or infer physical validity from digest equality.
