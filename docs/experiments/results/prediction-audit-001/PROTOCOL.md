# N045: when can a proxy reduce fresh confirmation effort?

16 October 2026. Frozen before executing the qualification. This is a constructed
finite arithmetic experiment, informed by the sources already inspected. It is
not a preregistered robot study, a new statistical method or an owner comparison.

## Decision

Determine whether randomized prediction audits are a defensible option to carry
into owner intake. The relevant mechanism is Prediction-Powered E-Values
(Csillag, Struchiner and Goedert, ICML 2025), Theorem 2.1. Independently implement
its scalar formula; do not copy its unavailable linked implementation. Do not
change Nisayon's runtime, finite confirmation obligations or historical results.

The endpoint is a constructed binary task outcome Y. Test the composite null
E[Y_t | past] <= 4/5 against improvement, with alpha 1/20. All study cells have
independent draws unless explicitly labelled as a violated-premise control.
These illustrative thresholds are not owner requirements or safety criteria.

An outcome predictor Z in {0,1} is available before deciding to acquire Y.
An independent Bernoulli(1/2) audit coin A decides acquisition. With a fixed
stake lambda=1/2, the factor is

`F = 1 + lambda*(Z - 4/5) + A*lambda*(Y-Z)/(1/2)`.

The four possible factors are 3/5, 11/10, 8/5 and 1/10. They are nonnegative.
Audit expectation conditional on Y,Z recovers `1 + lambda*(Y-4/5)` exactly.
Stop and support the alternative when the product first reaches 20; otherwise
return unresolved at 80 candidate contexts. No failure is reclassified as a
success. Predictions and audit coins never become real robot observations.

## Comparators and cells

Use a competent ordinary one-sided sequential likelihood-ratio test designed
before outcomes for Bernoulli success 19/20 versus 4/5. Its stake is 15/16,
and its factors are 1/4 and 19/16. Run it both with every outcome and with the
same 1/2 random acquisition rate, using factor one on skipped observations.
The latter is a sampling-rate control. Both receive the same endpoint and
error budget. This is a conventional published mechanism comparison, not a
comparison against an independently operated Nisayon competitor.

For each truth probability 4/5 (null boundary) and 19/20 (planning alternative),
run four prediction channels: perfect; sensitivity 99/100 and specificity 9/10;
always positive; and inverted. Also run a null channel that changes from
perfect to always positive after context 40. Preserve all cells. No fitting,
parameter search, Monte Carlo, model calls, policies, simulators or hardware.

Enumerate the full probability mass by dynamic programming over factor counts,
with absorbing first crossings. Use integer mass and rational comparisons, not
floating-point decisions. Retain the complete 1..80 curves: first-crossing
probability, unresolved probability, expected contexts and expected acquisitions
through stop/cap. Display decimals only after exact calculations. Count all
stopped and unresolved paths in expected effort.

The prespecified planning comparison is the earliest cap at which each method
supports the alternative with probability at least 4/5, if achieved by 80.
Report actual probabilities because discrete crossings can overshoot. Methods
that miss this target remain unresolved for this comparison. Do not choose a
different target or extend the horizon after seeing results.

## Controls and falsifiers

Check each factor's range and exact audit expectation, including fractional
predictions 0, 1/2 and 1. Reject invalid probabilities, predictions and audit
rates below the sufficient bound 5/11. Independently enumerate eight-step paths
for a nontrivial noisy null cell, six-step paths for both baselines, and a
six-step two-factor absorbing stress case; compare every curve to the dynamic
program. Require crossings in the noisy and stress controls. Verify probability
conservation at every step. Every valid
null cell must have crossing probability <=1/20.

Retain three deliberate invalid substitutions: always-positive predictions
without audits; stakes chosen using the current perfectly predictive covariate
under only a marginal-mean null; and an outcome drawn once then repeated as if
80 independent trials. Each must expose its false support or failed premise.
These are our misuse controls, not alleged defects in the cited papers.

## Cost and interpretation

For each comparison reaching the planning target, report expected acquisitions,
contexts and the break-even overhead under a declared linear accounting model.
Fresh execution can be saved only if Z and its context precede the avoidable
execution and omitted executions do not change later outcomes or sampling.
If Z requires a completed rollout, count every candidate rollout. Keep reset,
context construction, predictor computation, preparation, validation, review,
adoption and maintenance costs explicit; unmeasured costs are unknown.

Carry the option forward only as a conditional intake question if the arithmetic
and valid-null controls pass. A favorable cell cannot establish real savings,
calibration, physical sampling premises, quality preservation on a deployed
task, or superiority to a competent implementation of the same method. The
owner must still supply a live decision, permitted records, a frozen correction
and endpoint, valid fresh acquisitions and a fair complete-effort comparison,
followed by a separately untouched reuse case. Preserve pending engagements.
