Scope and architecture
Reviewed owning path:
 src/accelerate/utils/fsdp_utils.py:fsdp2_prepare_model
   capture original_sd after dtype upcast; move model to meta; establish ignored
   parameters and native sharding
 → fsdp2_load_full_state_dict
   rank-0 values → actual broadcast → managed DTensor / ignored tensor or buffer
   → preserve target dtype/contiguity → optional owned dictionary consumption
 → native model.load_state_dict(assign=True).

The caller owns original_sd and does not use it after this call. Borrowed callers
retain the default False behavior. Ownership is opt-in. Nonpersistent buffers have
a separate restoration path. Source inspection covered these callers/consumers,
the current function and relevant tests; it did not execute full prepare_model.
The protocol, source pins, scorer identity and conditions were frozen before the
base regression and candidate edit. Probe and scorer hashes stayed unchanged.

Only the reviewed loader AST is executed, with installed native torch as its
global dependency. No upstream package initialization, remote script, downloaded
checkpoint, build script or full upstream repository was executed. The sources
retain their licenses and exact Git blobs. A text transport initially added one
terminal LF; that was corrected and AST equivalence verified before any native
run. The original protocol and the correction remain visible.

The pre-existing Python 3.12.13 / Torch 2.11.0 environment was reused without an
installation or modification by this task. Runs use two CPU/Gloo processes on
macOS arm64. A CPU loader flag is exercised in both states; this is not execution
of CUDA CPUOffloadPolicy or pinned CUDA-to-CPU transfers.

Not run: CUDA offload/pinned memory, GPU peak memory, full Accelerate preparation,
forward/backward/optimizer steps, model training, real devices, Linux, CI, or an
independent owner trial. Dictionary lifetime does not establish that every backing
storage allocation is freed; local tensors and retained shards can share storage.
The old combined GPU RSS result is not a result for this new candidate.
