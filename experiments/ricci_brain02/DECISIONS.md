# Architecture decisions · RB-02, 27 November 2026

## Preserve the producer; project after execution

Brain 01 records already contain enough information to expose selection,
optimization, admission and application separately. The first scientific
inspection interface is therefore a deterministic read-only projection of sealed
episodes. It imports the existing strict JSON primitive and retains the existing
episode format. RB-02 owns quantities and validity; NL-01 owns rendering and its
service envelope. This is a research adapter, not a competing laboratory SDK.

The input contract includes an externally supplied manifest digest and the
reviewed producer's file identities. A source change needs deliberate semantic
review. A projection cannot qualify its producer or supply motor authority.
Reconstruction refuses any altered exported field. No explanation text is
generated from a model: the view exposes the actual residuals and decision map.

Rejected alternatives: a second evidence format, a general agent framework,
live JSON/network logging in control, and treating a viewer's schema as an
authority on scientific validity. None resolves the demonstrated problem.

## Preserve distinct clocks and native geometry

Available physical clocks retain acquisition/delivery/control meanings. Host
durations remain durations; unavailable stage timestamps remain null. Derived
task phase preserves the exact producer arithmetic, because reassociation can
change a hybrid branch. Native model entities are identified by model digest,
entity kind and index. G1 evidence is not retargeted onto conceptual Ricci geometry.

Rejected alternatives: a fabricated unified timeline, probability labels on
uncalibrated residuals, and visually plausible forces absent from the records.
These would obscure the numerical and causal mechanisms under investigation.

## Rerun changed futures; do not advertise incomplete checkpoints

MuJoCo integration state alone omits internal policy/filter/solver/sensor state.
This producer does not retain a complete continuation checkpoint. Changed-action
experiments run from reset through new closed-loop physics. Recorded-command
replay remains a reproduction check. A future checkpoint contract must bind all
omitted state and demonstrate continuation equivalence before branch execution.

## Keep numerical diagnosis separate from adaptation

The factorial and independent feasibility witnesses establish defects worth
investigating. They do not authorize choosing favorable phase branches, relaxing
residual tolerances or applying LP witnesses as control. Brain 01 remains the
baseline. A task-phase correction, an optimization correction and a policy
revision are separate interventions, each with its own freeze and confirmation.

No new predictive planner, acquisition model or morphology subsystem is justified
by the present evidence. This avoids carrying known numerical ambiguity into a
larger physical-information experiment. The EDPI symmetric negative control and
existing acceptance/confirmation rules remain unchanged.
